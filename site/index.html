What it does

One search. Five jobs.

The add-on is not a lookup box bolted onto Anki. It is the whole path from a word you met to a card you will review — without switching windows.

01

Seven ways to find the word

Search every installed dictionary at once, or narrow to a language group. Forward, Backward, Exact, Anywhere, Definition, Example and Pronunciation modes are one dropdown apart. Frequency comes with the result: stars, a numeric rank, and HSK, JLPT or CEFR labels when the lists are installed.

02

AI that reads the room

Bring your own model through an OpenAI-compatible endpoint or a local Ollama install. The prompt receives the term, part of speech, frequency and level context. Join several prompt templates with --- and a single call returns independent definition blocks, each with its own export tools.

03

Images and voices, on tap

DuckDuckGo Image Search and Forvo live in the dictionary group dropdown like any other source. Click an image or tick a native recording, then send it to the same field as the definition. No downloads, no asset folder, no context switch.

  • DuckDuckGo Image Search
  • Forvo
  • send to field

04

The card is the destination

Map any note type to an export template, then build the card in a dedicated exporter: multiple definitions, a sentence, notes, one image and one recording. Automatic modes pull definitions, DuckDuckGo images and Forvo audio for you. For existing decks, mass-export definitions from the Card Browser.

  • export templates
  • auto definitions
  • auto images
  • auto audio
  • mass export

05

Themes are a JSON system

More than a light/dark toggle. Fourteen colours control every panel, header, tab and highlight in the window. Apply a built-in theme instantly, derive a readable palette from two colours, or paste JSON from someone else. The gallery shows the live window, and one press undoes a wrong pick.
