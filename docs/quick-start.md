# Anki Dictionary Add-on Quick Start Guide

Get up and running in 5–10 minutes.

> The maintained version of this guide, with screenshots and troubleshooting, is at
> <https://alexander-nilsson.github.io/Anki-Dictionary-Addon/guide.html#quick-start>.

## 1. Install Anki 25.09+

Download the latest Anki from [https://apps.ankiweb.net](https://apps.ankiweb.net).

This add-on requires **Anki 25.09 or later**.

## 2. Install the Add-on

Download the `.ankiaddon` file from the [releases page](https://github.com/Alexander-Nilsson/Anki-Dictionary-Addon/releases).

In Anki:
1. Open **Tools → Add-ons**
2. Click **Install from file…**
3. Select the `.ankiaddon` file
4. Restart Anki

An **Anki Dictionary** menu will appear in Anki's top menu bar.

## 3. Install Dictionaries

Open the add-on settings: **Anki Dictionary → Dictionary Settings → Dictionaries** tab.

### Option A: Use the Wizard (recommended)

1. Click **Install Languages in Wizard**
2. Select your target language → translation language
3. Check the dictionaries you want
4. Confirm and wait for installation

### Option B: Install from a ZIP file

1. Select a language on the left
2. Click **Install Dictionary From File**
3. Pick a Yomichan or Migaku-format dictionary ZIP

## 4. Open the Dictionary

Press **Ctrl+W** (Windows/Linux) or **⌘+W** (Mac).

Or click **Anki Dictionary → Open Dictionary** in the top menu.

![Dictionary welcome screen](https://alexander-nilsson.github.io/Anki-Dictionary-Addon/assets/media/s01-welcome.webp)

## 5. Search a Word

Type a word into the search bar and press **Enter**.

You can also highlight any text in Anki and press **Ctrl+S** / **⌘+S** to search it immediately.

![Search bar with results](https://alexander-nilsson.github.io/Anki-Dictionary-Addon/assets/media/s02-search-light.webp)

## 6. Send a Definition to a Card

1. Open a card (Add, Edit, or Review)
2. In the dictionary, click the **Send to Field** button in a definition's header
3. The definition appears in the card's field
