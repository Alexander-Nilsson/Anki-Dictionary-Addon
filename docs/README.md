# Documentation

The maintained user documentation is the web guide:

**<https://alexander-nilsson.github.io/Anki-Dictionary-Addon/guide.html>**

It covers installation, all search modes, LLM definitions, images, Forvo audio, card
export, themes, settings and troubleshooting, with screenshots of the running add-on.

## In this folder

| File | Purpose |
|---|---|
| `user-manual.md` | Detailed in-repo reference. The web guide is maintained first. |
| `quick-start.md` | Short offline path from a clean Anki to a finished card. |
| `installation.md` | Installation reference. |
| `architecture.md` | Package layout, search pipeline and rendering. |
| `development.md` | Environment setup, build, linking and CI. |
| `testing.md` | Unit, integration and UI checks. |
| `adr/` | Architecture decision records. |
| `oldfiles/` | Archived Migaku manuals. Reference only. |
